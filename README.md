# fsyInteactive

An interactive gospel learning platform designed to help youth and families explore monthly *For the Strength of Youth* topics through scriptures, Church resources, team-based activities, and meaningful discussion.

## Goals

* Make gospel learning engaging and accessible.
* Support Young Women, Young Men, and combined/family settings.
* Provide interactive classroom activities using one shared screen.
* Offer at-home preparation and family learning experiences.
* Use a reusable monthly content structure.
* Avoid requiring accounts or storing personal student information.

## Initial Module

**October — Your Body Is Sacred**

The first module will focus on interactive learning, scripture connections, real-life scenarios, and a collaborative class adventure.
